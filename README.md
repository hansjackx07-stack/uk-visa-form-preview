# 英国签证家长表单原型（修订表版）

## 打开

`index.html` 为无需后端的单文件 HTML。建议用电脑 Chrome / Edge / Safari 直接打开。iPhone 聊天附件预览、微信文件预览可能禁用 JavaScript，因而仅显示静态首屏；正式在微信中交互填写需先将 HTML 部署为 HTTPS 静态网页。本原型不会联网、不会上传或发出数据。

## 本版变化

- 根据修订后的 `英国签证_字段对照表(1).xlsx`：封面单独一页，后续第一至第十页，共11页。蓝底标题和说明行原样读取；共63道编号题。
- JSON 键直接采用「对应字段ID」，姓名组分别输出两个字段，不再因字段重复而附加父亲、母亲、第N题等临时结构。
- 第16题改为搬入当前住址年月；不足24个月时显示第18题，并核验最近一处住址结束年月与当前搬入年月相同或早一月，之后逐组衔接，最早开始年月须早于或等于当前年月前24个月。
- 重复组解析 `子字段名[类型:选项/选项]`；「日期·可只填年月」通过勾选切换日/月精度，导出 `{ "value": "YYYY-MM" 或 "YYYY-MM-DD", "precision": "month" 或 "day" }`。
- 国家下拉从「选项清单」读取；第41题仅允许该表指定的澳加新美瑞士及欧洲经济区名单。学校、团期空白，用虚构示例，并标识为“示例”；选学校后筛选团期。
- 出行记录不早于十年前，不晚于今日，出入境日期先后校验；第40、41题数量不一致仅提醒，不阻止。
- 保持个人授权、条件显示、手机/邮编/邮箱、必填、错误定位、人工复核标记、本地自动保存、JSON 导出、清空重填。

## 简化与未实现

1. 学校/团期只有虚构示例，正式名单和团期公共信息未接入。
2. 省市区联动仅使用省、市、区文本框，未接中国行政区划库。
3. 文件只在页面显示名称，JSON 只存文件名、大小和类型；不上传文件、不保留文件内容，刷新后须重新选择。
4. 原表中系统处理的 OCR、证件交叉验证、自动翻译、汇率换算、官网录入、客服/人工派单等后端功能没有执行；只在 JSON 中输出人工复核标记及原因。
5. 官网分支字段仍需真实官网截图确认（包括英国出行及英国亲属等），原型未擅自设计官网字段。
6. 「选项清单」国家表中列出了有限欧洲国家：第41题仅提供这些已列出的、符合规则的国家，未自行扩充缺失的欧洲经济区国家。
7. `日期·可只填年月` 的跨精度先后比较：当某月与具体日期重叠时，允许通过，不能凭未知的日数确定真实先后。

## 仅用于测试

请使用虚构数据；浏览器本地存储并非敏感资料的安全保存方案，不适合直接作为正式签证申请收件系统。正式上线需补充加密传输、身份鉴权、数据存储、隐私合规及备份等能力。
