# 英国签证家长表单原型（修订表版）

## 打开

`index.html` 为无需后端的单文件 HTML。建议用电脑 Chrome / Edge / Safari 直接打开。iPhone 聊天附件预览、微信文件预览可能禁用 JavaScript，因而仅显示静态首屏；正式在微信中交互填写需先将 HTML 部署为 HTTPS 静态网页。本原型不会联网、不会上传或发出数据。

## 本版变化

- 根据修订后的 `英国签证_字段对照表(1).xlsx`：封面单独一页，后续第一至第十页，共11页。蓝底标题和说明行原样读取；共63道编号题。
- JSON 键直接采用「对应字段ID」，姓名组分别输出两个字段，不再因字段重复而附加父亲、母亲、第N题等临时结构。
- 第16题改为搬入当前住址年月；不足24个月时显示第18题，并核验最近一处住址结束年月与当前搬入年月相同或早一月，之后逐组衔接，最早开始年月须早于或等于当前年月前24个月。
- 重复组解析 `子字段名[类型:选项/选项]`；「日期·可只填年月」通过勾选切换日/月精度，导出 `{ "value": "YYYY-MM" 或 "YYYY-MM-DD", "precision": "month" 或 "day" }`。
- 国家下拉从「选项清单」读取；第41题仅允许该表指定的澳加新美瑞士及欧洲经济区名单。学校、团期空白，用虚构示例，并标识为“示例”；选学校后筛选团期。
- 出行记录不早于十年前，不晚于今日，出入境日期先后校验；第40、41题数量不一致仅提醒，不阻止。
- 保持个人授权、条件显示、手机/邮编/邮箱、必填、错误定位、人工复核标记、本地自动保存、可读填写记录导出（HTML，可阅读和打印）、清空重填。

## 简化与未实现

1. 学校/团期只有虚构示例，正式名单和团期公共信息未接入。
2. 省市区联动仅使用省、市、区文本框，未接中国行政区划库。
3. 文件仅在当前页面会话中显示名称，不上传、不保留文件内容；本地暂存和进度备份 JSON 均排除附件内容及文件名（含重复组内的相关文件），刷新或恢复后必须重新选择。可读 HTML 填写记录仍只展示当前会话的附件名称。
4. 原表中系统处理的 OCR、证件交叉验证、自动翻译、汇率换算、官网录入、客服/人工派单等后端功能没有执行；只在 JSON 中输出人工复核标记及原因。
5. 官网分支字段仍需真实官网截图确认（包括英国出行及英国亲属等），原型未擅自设计官网字段。
6. 「选项清单」国家表中列出了有限欧洲国家：第41题仅提供这些已列出的、符合规则的国家，未自行扩充缺失的欧洲经济区国家。
7. `日期·可只填年月` 的跨精度先后比较：当某月与具体日期重叠时，允许通过，不能凭未知的日数确定真实先后。

## 仅用于测试

请使用虚构数据；浏览器本地存储并非敏感资料的安全保存方案，不适合直接作为正式签证申请收件系统。正式上线需补充加密传输、身份鉴权、数据存储、隐私合规及备份等能力。

## 公开预览部署说明

已将姓名和地址提示替换为虚构测试示例，并增加仅供测试提示。部署于 GitHub Pages，使用虚构资料测试；提交按钮仅在本地生成核对摘要，不向任何服务器提交填写数据。

## 填写完成后的核对页

核对页按主题分组，以中文标签展示填写内容，并可从各分组返回修改。“保存填写记录”导出可独立阅读和打印的 HTML 文件，另有独立的进度备份 JSON 下载及导入按钮，供恢复填写使用。导出只包含当前可见的填写内容和附件名称，不包含附件文件内容；保存不会发送资料。


## 暂存、恢复与跨设备备份

- 每页及核对页均有明显的“暂存 / 保存进度”“恢复继续填写”按钮，显示保存时间或失败提示；输入、选择及翻页仍自动保存，沿用原有 localStorage 键与 try/catch。
- 重开同一设备、同一浏览器、同一网址时自动恢复文字、选项和页码，也可点击恢复按钮。换设备、换浏览器或清除浏览器数据后无法直接恢复。
- 展开“换设备：下载备份 / 导入恢复”，可下载 JSON 并在另一设备本地导入。导入有格式、版本、页码、大小（2MB）检查和覆盖确认；失败时保留当前填写。
- 备份包含未加密的填写信息，请妥善保管，勿公开分享。备份仅在本机生成和读取，无上传、分析或其他网络请求。
- 所有附件的内容、文件名及其他附件记录均不进入暂存或进度备份，旧版已保存的附件记录恢复时也会排除。身份证正反面仍可分批追加及单独删除。恢复原材料上传页之后的进度时，会返回材料上传页重新选择附件，并再次确认提交。
- 保存不可用、记录损坏及清除失败均显示中文提示。清空重填会清除本站暂存；已下载的备份和填写记录需自行删除。
- 首页材料准备清单直接读取现有第54—61题的标题和提示，不新增材料要求，并说明正反面分类准备、特殊情况相关文件选填、测试版仅用虚构资料。
